# 🌍 Olá, Mundo pelo Mundo! (Carrossel Interativo)

Um projeto web simples e elegante que exibe a clássica frase de programação *"Olá, Mundo!"* em sete idiomas diferentes, utilizando um carrossel moderno e totalmente centralizado na tela.

---

## 🚀 Demonstração

O projeto foi construído pensando na simplicidade e na experiência visual. Ele centraliza o conteúdo perfeitamente na tela e oferece transições suaves entre as línguas.

### Idiomas incluídos:
* 🇧🇷 Português (Olá, Mundo!)
* 🇺🇸 Inglês (Hello, World!)
* 🇪🇸 Espanhol (¡Hola, Mundo!)
* 🇫🇷 Francês (Bonjour, le Monde!)
* 🇮🇹 Italiano (Ciao, Mondo!)
* 🇩🇪 Alemão (Hallo, Welt!)
* 🇯🇵 Japonês (こんにちは世界 !)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido de forma nativa, sem a necessidade de frameworks ou bibliotecas externas:

* **HTML5:** Estrutura dos slides e elementos de navegação.
* **CSS3:** Estilização, gradiente de fundo, responsividade e animações de transição (`ease-in-out`).
* **JavaScript (Vanilla):** Lógica do carrossel (passagem automática, botões de próximo/anterior e indicadores em formato de bolinhas).

---

## 📦 Como Executar o Projeto

Você pode rodar este projeto localmente de duas maneiras:

### 1. Usando a extensão Live Server (Recomendado)
Se você utiliza o **Visual Studio Code**:
1. Instale a extensão **Live Server**.
2. Abra a pasta do projeto no VS Code (`File > Open Folder`).
3. Abra o arquivo `index.html`.
4. Clique no botão **Go Live** localizado na barra inferior do editor.

### 2. Execução Direta
1. Navegue até a pasta onde o arquivo foi salvo.
2. Dê um duplo clique no arquivo `index.html`.
3. O projeto abrirá diretamente no seu navegador padrão.

---

## 🎮 Funcionalidades

* **Navegação pelas Setas:** Botões laterais `❮` e `❯` para passar manualmente.
* **Indicadores de Navegação:** Bolinhas na parte inferior que mostram qual slide está ativo e permitem saltar direto para uma língua específica.
* **Loop Infinito:** Ao chegar no último idioma, o carrossel retorna automaticamente para o primeiro (e vice-versa).
* **Reprodução Automática:** Os slides mudam sozinhos a cada 4 segundos caso o usuário não interaja.
